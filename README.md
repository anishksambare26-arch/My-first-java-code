# ATM Machine - Java

Simple ATM simulation with PIN security - My first Java project.

## Features
- Secure login with Account No: 2008 and PIN: 1234
- Check Balance (Starting: 50000)
- Deposit Money
- Withdraw Money with balance check
- Exit option

## How to Run
javac ATM.java
java ATM

## What I Learned
if-else, while loop, Scanner, security check, commenting code
